| Android 状态 | Route/Screen 分离、只读 StateFlow 与 update、依赖可替换、ViewModel 行为测试；书签读取失败可恢复，历史写入失败不丢失已加载列表 |
| 缓存与播放 | 清理协调播放器、预加载、磁盘缓存和索引；取消与初始化失败关闭已取得资源；可选预加载的磁盘统计失败不会使工作协程崩溃；保持单前台播放器及既有内存/磁盘预算 |

## 实质发现的处理

以下按问题归并，不把格式化改动计为缺陷数量。

| 级别 | 位置 | 问题与处理 |
| --- | --- | --- |
| high | `internal/app/app.go` | 关闭顺序可能让工作者访问已关闭数据库；统一取消、等待和关闭所有权，生命周期测试覆盖 |
| medium | `internal/app/app.go` | 普通扫描与强制扫描请求合并可能丢失强制标志；以原子标志保留，测试覆盖 |
| medium | `internal/jobs/queue.go` | 把暂时数据库读取失败当失效任务，以及忽略完成/释放写入失败；区分错误并传播、退避或记录，取消场景测试覆盖 |
| medium | `internal/library/list.go` | 末页仍带下一页游标；利用额外一行与反向边界 EXISTS 判断，正反排序、分页、锚点及 HTTP 契约测试覆盖 |
| medium | `internal/scanner/stage.go`、`scan.go` | 临时库 chmod 和失败清理错误丢失；改为创建时 0600、合并失败错误，扫描结束清理失败记录日志 |
| medium | `internal/thumbnail/reconcile.go` | 临时封面属性读取失败被吞掉；只忽略文件已被清理的情况，其他读取错误返回并测试 |
| medium | `CacheCoordinator.kt`、`VideoCache.kt` | 缓存重建/取消与 loader 创建失败可能遗留资源；明确交接所有权并关闭失败路径资源 |
| medium | `LibraryViewModel.kt` | Room 书签读取未进入错误边界，访问记录写入失败会覆盖已加载页面；加入可恢复失败状态并保持列表 |
| medium | `PlayerViewModel.kt` | 服务端末页省略下一游标后，客户端仍等待空页才设置末尾状态；改为首次锚点页和后续页直接判定游标，覆盖反向保留与窗口淘汰后的状态恢复 |
| medium | `TokenPolicy.kt`、`ConnectionPolicy.kt` | 非法令牌可能在构造 HTTP 头时抛异常；与服务端统一验证可见 ASCII 和 4096 字符上限 |
| medium | `AlbumBubble.kt`、`FolderContent.kt` | Perfetto 记录单次相册预取测量最高 10.49 ms；每项 BoxWithConstraints 在测量阶段组合整组内容。改为列表容器一次取得准确宽度，保留首帧稳定高度和键值，复测深锚点恢复与滚动 |
| medium | `NeighborPreloader.kt` | 磁盘剩余空间查询在可选预加载的错误边界外；纳入失败处理，仍传播协程取消 |

扫描临时库创建/清理与分页变化不增加源媒体写入。分页仍在同一个只读事务中，正向最多读取 `limit + 1` 行；反向额外一次 EXISTS 使用既有 `entry_*` / `entry_kind_*` 覆盖范围索引，代价为 O(log N + page size)，没有 COUNT、OFFSET、全表排序或写事务。12 种列/方向/筛选组合的实际 EXPLAIN 均使用对应覆盖索引；规模验证见验收记录。

## OCR 审查方式

先实际运行 `open-code-review` 的 `ocr review`，由于本机未配置模型端点而退出 1。用户随后明确选择本机托管代理模式；使用 `open-code-review-delegate` 的 `preview`、`rule` 获取工作区范围与规则，由宿主代理逐文件审查差异、新文件和调用上下文。

实现者与审查者是同一代理，**不是独立外部模型复核**。最终暂存范围共 149 个可审查条目（148 个源码/配置/脚本条目及审查清单自身），149/149 已检查，0 跳过；每个 `(path, status)`、源文件 SHA-256 与覆盖统计见同目录 `2026-11-01-compliance-files.json`。清单自身为自引用元数据，校验结构和其他源文件摘要，不记录自身摘要。OCR 默认排除的 Go 测试、资源和文档另做行为验证及一致性检查。审查覆盖率只描述所列变更，不是无缺陷证明；性能失败与未测条件不因代码审查完成而豁免。

- 未升级 Go/Android 的语言和依赖基线。Compose 预览、Media3 的 OkHttp 适配、Room 插件与 coroutines-test 复用版本目录中已有的对应版本，分别用于预览、统一 HTTP 栈、schema 导出和协程测试。

- 全局允许 HTTP 是 2026-10-20 用户决定，已在 Android README 记录；本次不擅自改回指定主机列表。
- 中英文 README 的例外表保留 `config.Source.Environ`，并补全与已有目录/实施/设计决策一致的边界：`jobs/tests` 包名、不跟随任何媒体符号链接的描述符访问、领域 SQL 与写入计量、内部纳秒精度、版本化二进制缓存。通用规范正文未改；依据和重新评估条件逐项列明。
